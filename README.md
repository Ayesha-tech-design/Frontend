SmartEduX - AI-Based Smart Learning System


SmartEduX is a comprehensive AI-powered platform designed to enhance the learning experience for students through automated note generation, summarization, and interactive study tools.





Key Technical Highlights

Backend Architecture: Built with Django REST Framework & PostgreSQL for a robust and scalable API.

Security & Environment: Securely managed secrets using Environment Variables (.env) to protect database and API credentials.

Authentication: Implemented JWT (JSON Web Tokens) for secure, stateless user authentication.

AI Integration: Powered by the Gemini API for automated video summarization and transcript generation.

Database Management: Efficient data handling for users, courses, and AI-generated study notes.






Tech Stack

Framework: Django & Django REST Framework

Database: PostgreSQL

Security: SimpleJWT (Authentication), python-dotenv (Configuration)

AI: Google Gemini API
